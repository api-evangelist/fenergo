# Fenergo (Fen-X SaaS Platform)

> Fenergo is a financial-services SaaS vendor whose Fen-X platform delivers Client Lifecycle Management (CLM),
> KYC, AML screening, client onboarding, transaction monitoring and regulatory compliance to banks and asset
> managers. The platform is API-first and built on CQRS with event sourcing: nearly every domain ships a
> separate Command (write) and Query (read) REST service. Fenergo publishes 145 OpenAPI 3.0/3.1 contracts
> covering 2,381 operations across 108 CLM services, 8 Transaction Monitoring services and a SCIM 2.0 identity
> service. Authentication is OAuth 2.0 client_credentials against a Duende IdentityServer, with mTLS available
> and 105 published granular fenx.* scopes. Every CLM call requires an x-tenant-id header.

## How to call it

- POST https://identity.fenergox.com/connect/token with grant_type=client_credentials, client_id, client_secret and a space-separated `scope` (max 300 characters). The access token is a Bearer JWT valid for 900 seconds — cache and reuse it; the identity endpoint allows 100 token requests per IP per 5 minutes.
- Send `Authorization: Bearer <token>` AND `x-tenant-id: <tenant GUID>` on every CLM call. A missing tenant header returns HTTP 400 with errorCode MissingTenantHeader.
- Regional deployments follow https://identity.{region}.fenergox.com and https://api.{region}.fenergox.com; api.fenergox.com is the default host in the published documentation.
- Writes go to a Command service, reads to the matching Query service. The platform is eventually consistent: a successful write is not immediately visible on the Query side. Subscribe to the matching event notification or poll.
- There is no idempotency key. Writes are protected by optimistic concurrency instead — 151 operations return 409 "Conflict saving changes in expected version".
- Rate limits: 200 req/s per production tenant (burst 50), plus per-domain minute/hour/day limits. On 429 read X-Rate-Limit-Remaining and X-Rate-Limit-Reset (CLM) or Retry-After (Transaction Monitoring) and back off exponentially.
