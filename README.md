Fenergo is an Irish-headquartered financial-services SaaS vendor whose Fen-X platform delivers Client Lifecycle Management (CLM), Know Your Customer (KYC), AML screening, client onboarding, transaction monitoring and regulatory compliance to banks, asset managers and financial institutions. The platform is API-first and built on CQRS with event sourcing, so nearly every domain ships a separate Command (write) and Query (read) REST API. Fenergo publishes 145 OpenAPI 3.0/3.1 contracts covering Entity Data, Journey, Policy, Risk, Screening, Associations, Documents, Document Generation, Product, Deals, Collateral, Financial Analysis, Credit Screening, Data Migration, ETL, Bulk Load, Audit, Authorization, Identity, SCIM 2.0, Data Protection, Event Ingress, Event Notifications, Webhooks, Portal, Reporting, Dashboards, Digital IDV, Digital Agents and Transaction Monitoring. Authentication is OAuth 2.0 / OpenID Connect client-credentials against a Duende Identity Server, with mTLS available and 105 published granular fenx.* scopes.

**Areas:** Compliance · Financial Services · KYC · AML · Onboarding · Client Lifecycle Management · Transaction Monitoring · Screening · Risk Management · RegTech · Software-as-a-Service · Identity

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Fenergo: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
